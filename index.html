Mastering Kadane's Algorithm

Explore the elegance, applications, and core principles of one of dynamic programming's most celebrated solutions.

What is Kadane's Algorithm?

Kadane's Algorithm is a dynamic programming approach designed to find the maximum sum of a contiguous subarray within a one-dimensional array of numbers. Its linear time complexity and constant space complexity make it exceptionally efficient.

When to Use?

This algorithm is specifically tailored for problems requiring the largest possible sum from a sequence of adjacent numbers in an array, particularly effective when the array contains both positive and negative values.

Why it Works?

Kadane's algorithm leverages two core dynamic programming principles: optimal substructure (solutions to subproblems build the global solution) and greedy choice (making the locally optimal decision at each step, ensuring the $current\_sum$ never becomes a "burden" on future sums by restarting if it drops below zero).

The Core Approach

The algorithm processes the array in a single pass, maintaining two key variables: the maximum sum ending at the current position and the overall maximum sum found so far.

1

Initialization

Set $current\_sum$ and $largest\_sum$ to the value of the first array element (or negative infinity for $largest\_sum$).

2

Iterative Update

For each subsequent element, update $current\_sum = \text{max}(\text{element}, current\_sum + \text{element})$. This decides whether to extend the current subarray or start a new one.

3

Global Maximum

After updating $current\_sum$, update $largest\_sum = \text{max}(largest\_sum, current\_sum)$ to keep track of the overall best.

Time Complexity

O(N)

Single pass through the array.

Space Complexity

O(1)

Only a few variables needed.
